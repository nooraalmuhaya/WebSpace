# Documentation

| Folder | Contents |
|--------|----------|
| [requirements/](requirements/) | Functional and non-functional requirements, user stories, backlog |
| [design/](design/) | Architecture notes, wireframes and UI design |
| [diagrams/](diagrams/) | ERD, use case, activity, workflow, authentication flow and state diagrams (editable sources) |
| [testing/](testing/) | Test plan, test cases and test results |
| [user-guide/](user-guide/) | End-user guides for Students, Tutors and Administrators |

Guidelines:

- Keep each document in one place only; link to it instead of copying it.
- Commit editable sources (`.md`, `.mermaid`, `.drawio`). Commit exported images/PDFs only when they are needed (e.g. embedded in a document).
- Do not commit temporary Word/PDF exports of the assignment report unless the team agrees they belong here.
